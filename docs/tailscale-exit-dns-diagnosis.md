# Диагностика HTTPS через Tailscale Exit Node

## Постановка задачи

На одноруком шлюзе OpenWrt проверочные сайты показывали ожидаемые выходы Tailscale, VLESS и direct. При этом с Windows-клиента `curl` к `https://chatgpt.com/` через один Tailscale Exit Node завершался таймаутом, через другой работал. Обычный `curl`, запущенный непосредственно на проблемном выходном узле, тоже работал. Нужно было воспроизвести сбой, определить, где прерывается соединение, и предложить исправление.

Диагностика проводилась по SSH через Tailscale. На OpenWrt выходы переключались штатными скриптами. После тестов требовалось восстановить исходную конфигурацию и проверить трафик с клиента.

## История теста

1. Исходная конфигурация использовала рабочий выход. С Windows получен HTTP 200. Конфигурации двух вариантов различались только выбранным Exit Node.
2. После переключения контрольный `curl` к `2ip.io` сначала давал таймауты. В журнале sing-box вскоре после запуска было сообщение `missing Tailscale IPv4 address`. При повторном прогоне контрольный запрос подтвердил публичный IP проблемного выхода, после чего обычный `curl` к `chatgpt.com` по-прежнему давал TCP-таймаут примерно через пять секунд.
3. Windows использовала DNS роутера. Роутер и его локальный вышестоящий DNS возвращали одну пару IPv4-адресов. Системные резолверы обоих Exit Node на момент теста возвращали другую пару.
4. С Windows через проблемный выход принудительно проверили каждый адрес, сохраняя имя `chatgpt.com` для TLS и HTTP через `curl --resolve`. Оба адреса локального DNS давали таймаут, оба адреса резолвера выходного узла дали HTTP 200. Один успешный адрес перепроверили после подтверждения выходного IP с Windows.
5. Прямой `curl --resolve` на проблемном выходном узле к обоим адресам локального DNS также дал таймаут. На рабочем выходном узле оба этих адреса дали HTTP 200. Захват на проблемном узле показал повторные TCP SYN из Tailscale и их отправку после NAT во внешний интерфейс. Ответных SYN-ACK для этой пары на внешнем интерфейсе не было.
6. Исходную конфигурацию восстановили и сверили по содержимому. После запуска с Windows снова подтверждены публичный IP исходного выхода и HTTP 200 для `chatgpt.com`.

## Вывод

При смене выхода Windows продолжала использовать адреса из локального DNS. Обычный запрос с самого выходного узла использовал другую пару. DNS-запросы успешно завершались. Наблюдаемый отказ происходил на этапе TCP до TLS и зависел от сочетания выхода и адреса назначения. Захват не установил, где именно за внешним интерфейсом терялись ответы. Короткое окно запуска Tailscale наблюдалось отдельно, а таймаут сайта сохранялся после подтверждения готовности выхода.

## Предложения по исправлению

**Рабочий обход.** Использовать исходный Exit Node. Через него доступ с Windows подтверждён после восстановления конфигурации.

**Пилот отдельного DNS.** Для `chatgpt.com` и его поддоменов настроить условную пересылку из dnsmasq на отдельный DNS-вход sing-box на loopback. Запросы с этого входа отправлять к DoH-резолверу через тот же `tailscale-exit`, который обслуживает HTTPS. Для остальных доменов сохранить текущий DNS. Предусмотреть начальное разрешение имени DoH-сервера без цикла и явную ошибку при недоступности туннеля. Проверенный непосредственно на проблемном узле DoH-запрос вернул оба рабочих IPv4-адреса. На роутере эта схема пока не испытывалась. Адреса назначения следует получать по DNS. [Документация sing-box по DoH](https://sing-box.sagernet.org/configuration/dns/server/https/)

**Приёмка.** После каждого переключения сначала подтвердить ожидаемый публичный IP запросом к `2ip.io` с Windows. Затем проверить свежие A и AAAA от DNS роутера и запустить обычный `curl` без `--resolve` и без `-4`. Сверить фактический адрес и выход по журналу sing-box. У PoC перехват IPv4, поэтому поведение AAAA нужно проверить отдельно. Если IPv6 обходит выбранную политику, для пилота можно ограничить ответы домена IPv4. Учесть кэш Windows и браузерный Secure DNS. Повторить тест с обоими выходами, проверить контрольные запросы VLESS и direct, затем проверить откат. Расширять DNS-правила на другие категории Tailscale после успешной приёмки.
