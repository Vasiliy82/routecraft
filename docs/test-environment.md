На обеих доступны `apk`, `parted` и `blkid`; `sing-box` в PATH не найден. VM1 дополнительно содержит `resize2fs` и `grub2-editenv`.

После автономного расширения и исправления метаданных окончательный `e2fsck -f -n` на обеих VM завершился с кодом 0. Обычная конфигурация GRUB восстановлена; временная среда удалена с VM. Локальные журналы, копии исходного GRUB и GPT-метаданные находятся в `archive/disk-backups/`, который не отслеживается Git. Для VM1 исходная первичная GPT сохранена непосредственно с неё; отдельная резервная GPT в её каталоге скопирована с VM2 после проверки идентичности первичных GPT и явно так названа.
