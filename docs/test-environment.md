Обе VM при первичной инвентаризации имели ядро `6.12.112`, релиз `r33311-981c978eff`, примерно 98,3 МБ корневой файловой системы, 73,6 МБ свободно и примерно 492,7 МБ tmpfs `/tmp`. На обеих после reboot доступен `apk`, а `sing-box` в PATH не найден. С обеих VM прошёл ping до `.254` и `nslookup openwrt.org 192.168.80.254`; на VM1 также проверено разрешение через `127.0.0.1`. DNS в `/etc/resolv.conf` указывает на локальный listener, upstream `.254` задан через UCI. Перед установкой пакетов заново проверить место и зависимости: на этих образах root-раздел существенно меньше исторической VM из handoff.

Вход: `ssh root@192.168.80.241` или `ssh root@192.168.80.242`. Использовалась доступная SSH-аутентификация текущего окружения; пароль не предоставлялся. Если VM не отвечает после перезагрузки, пользователь может восстановить снапшот. Указанные VM — тестовые; исторический TOP50 `.253` не изменять без отдельного согласования.
