# Архитектурные решения и открытые вопросы

## Имена и язык

Проект и предлагаемый CLI — `routecraft`, LuCI — `luci-app-routecraft`; provider и геоданные имеют самостоятельные логические границы. Go предварительно выбран для будущего контроллера: единый бинарник и кросс-компиляция подходят OpenWrt. Это проектное решение требует подтверждения сборкой для целевой версии и оценки размера; версия компилятора и библиотеки должны быть зафиксированы при реализации.

## Хранение и старт

Предусмотреть `ram-only`, `ram+immutable-seed` и `persistent-last-known-good`; свойства описаны в `architecture.md`. Default для flash не утверждён до проверки лицензий, размера и доступной RAM. После холодного запуска RAM-only без источника не обеспечивает offline boot. При отсутствии обязательных данных не использовать скрытый direct fallback.

## Две Tailscale identity

Системный Tailscale предназначен для управления, embedded endpoint sing-box — для выбранного Exit Node. Они имеют отдельное состояние и не должны изменять маршруты друг друга. Использование системного `tailscale set --exit-node` для реализации пользовательских правил исключено. Возможности встроенного endpoint и реальный egress остаются предметом испытаний.

## Неизвестные источники и исходы

Подтвердить происхождение и лицензию каждой категории, особенно `ru-blocked` и `cursor`; зафиксировать адрес, версию, состав и обновление. Наличие источника не считается подтверждённым из-за одной записи в старом PoC. Для gateway и Exit Node не объявлять поддержку до измеренного реального пути.
