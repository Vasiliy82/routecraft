# Тестирование

Реальный TCP и UDP через временный TPROXY между тестовыми VM уже проверены; результаты и ограничения описаны в `development-journal.md`, запуск — в `../tests/integration/README.md`. Network namespaces не являются частью продукта и будут применяться как тестовый инструмент только при обоснованной необходимости. Ещё требуются два независимых клиента, проверка SNAT и автоматизация полного набора E2E.

Unit и contract тесты запускаются без root, внешней сети и настоящих учётных данных: порядок и OR, ошибки YAML, имена, default, DNS, MagicDNS, статическое explain, детерминированная компиляция, фиктивные источники SRS и сбои provider. Контрактные тесты проверяют актуальный зафиксированный sing-box `check` и изолированный startup: первый отдельно не подтверждает второй.

Updater и подписку проверяют локальным HTTP mock на 404, timeout, обрыв, повреждение, повтор, гонки и сохранение прошлого поколения. Реальные ключи и сеть пользователя исключены из CI по умолчанию. Для полноценной приёмки отдельно выполнять реальное прохождение direct, VLESS, gateway и Tailscale Exit Node, включая DNS, после загрузки, при отказе и восстановлении. Отмечать mock и реальный путь как разные результаты. Все AT-01…AT-26 перечислены в `requirements.md`.

Реализованы цели `make lint`, `make test`, `make test-offline` и `make build`. Цели `make bootstrap`, `make test-e2e`, `make package` ещё предстоит создать. Основные тесты работают без root; ручной сетевой тест требует привилегий на тестовых VM. Публиковать версию среды, команды, результаты pass/fail/skip и ограничения.
