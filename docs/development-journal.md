## 2026-11-13 — CLI и проверка sing-box

- Проверка: `go test ./...`, CLI validate/compile и `sing-box check` 1.13.21 прошли. На VM1 временный локальный sing-box вернул HTTP через direct и отклонил запрос по порту при несовпадающем домене — OR работает в реальном процессе.
- Вывод: синтаксис и локальный путь подтверждены; TPROXY, транзит клиентов и VPN ещё не проверены. Namespace для этой проверки не потребовался.

## 2026-11-13 — прозрачный TCP между VM

- Проверка: VM2 получила `HTTP/1.1 301` от `1.1.1.1:80`; nft показал 6 пакетов, sing-box зафиксировал inbound от VM2 и direct к цели. После теста проверено удаление nft-таблицы, ip rule и маршрутов на обеих VM.
