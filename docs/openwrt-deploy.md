# Развёртывание и диагностика OpenWrt

Пакеты и команды RouteCraft пока не реализованы. Эта страница фиксирует целевой порядок: проверить архитектуру и версию OpenWrt и sing-box, совместимость пакетного менеджера, доступное хранилище и память; сохранить конфигурацию; развернуть пакет и необходимые данные; проверить кандидат вне активной сети; применить и подтвердить DNS и фактический TCP/UDP путь. Должны существовать понятные status, doctor, diff, apply и rollback. При отказе возвращается и конфигурация, и сетевое состояние.

При загрузке tmpfs пуст: procd должен дождаться появления и проверки требуемых SRS перед запуском sing-box, не блокируя администрирование. Поведение offline зависит от выбранного storage mode; RAM-only не обеспечивает cold boot без источника. Не подменять недоступный VPN прямым выходом. После обновления или reboot проверять работающий путь клиента и отсутствие дублированных nft/ip rules.

Для обследования VM используйте `uci show network.lan`, `cat /proc/sys/kernel/hostname`, `ip -4 addr`, `ip -4 route`, `cat /etc/openwrt_release`, `df -h / /tmp`. Установочная VM может не иметь отдельной команды `hostname`. Сначала обращаться к `docs/test-environment.md`; исторический TOP50 не изменять без отдельного согласования.
