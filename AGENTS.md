# Инструкции для работы с RouteCraft

RouteCraft — проект декларативной маршрутизации OpenWrt. Состояние на 12.11.2026: проект находится на стадии подготовки; наличие этого файла и документации не означает, что продукт или его тесты реализованы.

Начинайте с `README.md`, `docs/requirements.md`, `docs/architecture.md`, `docs/test-environment.md` и соответствующего живого ExecPlan. `docs/execplan.md` описывает подготовку; `docs/development-execplan.md` — разработку и тестирование. При расхождениях действуют прямые указания пользователя, затем актуальные решения в этих документах. Исходные документы находятся в игнорируемом локальном `archive/source-handoff/` и не гарантированно доступны из Git.

Целевая политика обрабатывается сверху вниз, первое совпадение побеждает, фильтры внутри правила объединены ИЛИ, последнее правило — default. Не подменяйте отсутствующие категории пустыми наборами; не переключайте недоступный VPN на direct без явной политики. VLESS provider, обновление геоданных и apply не должны конкурировать за запись единой активной конфигурации. Для изменений сети проектируйте идемпотентность и проверяемый откат.

Тестовые VM и тестовые учётные данные приведены в `docs/test-environment.md`; пользователь разрешил хранить их в репозитории. Не путайте VM1/VM2 с историческим TOP50 `.253`: его нельзя изменять без отдельного согласования. Не отправляйте тестовые подписки и ключи в публичные журналы или CI без необходимости. Не предполагайте установленные версии программ или доступность стендов без проверки.

При разработке обновляйте `docs/development-execplan.md`, фиксируйте решения и доказательства. Проверяйте поведение соответствующими тестами, включая сетевые E2E для фактических маршрутов, а не только синтаксис JSON или статус процесса. Заявляйте только реально проверенные функции; тестовые заглушки и настоящие Tailscale/VLESS интеграции указывайте отдельно. Команды `make test`, `make test-offline`, `make test-e2e` и `make package` пока являются требованиями будущего проекта, а не существующими командами.
